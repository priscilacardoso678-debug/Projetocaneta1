# Projetocaneta1 - Precision Series

Site da Precision Series desenvolvido em [Astro](https://astro.build/).

## 🚀 Comandos

| Comando | Ação |
| :--- | :--- |
| `npm install` | Instala as dependências |
| `npm run dev` | Inicia o servidor local em `http://localhost:4321` |
| `npm run build` | Gera a build de produção em `./dist/` |
| `npm run preview` | Pré-visualiza a build localmente |
